Mini-project, 2026

Wireless sensor network on Zolertia Z1

Two boards talk over a low-power wireless link: every 5 seconds the client contacts the server, which orders an LED pattern. Both boards count from 0 to 7 in binary in sync, and the client confirms what it applied.

I simulated it in Cooja first, then flashed the same firmware onto two real boards. Biggest lesson: simulating before deploying saves a lot of time.

  • Contiki OS
  • Cooja
  • Zolertia Z1
  • 6LoWPAN
  • RPL
  • C

Project supervised by Professor Tahar Ezzedine.

Reinforcement learning project, 2026-2027

Intrusion response agent

An intrusion detector raises alarms but doesn’t decide what to do. I built an agent that learns the response itself (investigate, block or isolate) by training only inside a simulated digital twin of a network node, using first-visit Monte Carlo control.

It found the optimal policy and matched the exact solution computed with value iteration. Monte Carlo also settled 27 to 31 times sooner than SARSA, Q-learning and Expected SARSA. With a noisy detector across 50 simulated nodes, nodes were compromised 2.3% of the time, against 88.4% with a passive IDS.

  • Python
  • Reinforcement learning
  • Monte Carlo control
  • Digital twin
  • Q-learning / SARSA

With Yosser Jabloun, supervised by Ms. Wafa Mefteh.
